## Where it sits

```
chant source ──build/lint──▶ graph IR ──behold──▶ live graph + drift + (delegated) actions
              (deterministic)          (server + browser)
```

behold reads what [chant](https://github.com/INTENTIUS/chant) compiled and what the cloud reports, and shows you the difference. As a viewer over a compiler, it can say plainly which parts it could not read.

## What the colours say

Green means managed and amber means foreign. Blue is declared but not yet observed. The colours come from reading the live estate, and behold hosts no state file. A resource behold could not read shows as unobserved, which is a separate claim from absent. [Reading the graph](/behold/using/reading-the-graph/) has every colour and zoom tier.

## Where writes run

Sync starts the `ApplyOp` you committed, and Adopt starts your `ReconcileOp`, which opens a pull request a person merges. Deploy runs chant with the credentials behold was started with. A terragucci or SQL Yodeler repo leaves every write to its pipeline. [What behold is](/behold/start/what-it-is/#read-only-core-delegated-writes) covers the rest.
